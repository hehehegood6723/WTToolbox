## No game files are redistributed

The repository contains **no** War Thunder assets. It reads files that are
already on your disk (configurations, replays, logs, the `sound` folder) and
writes only to its own directory under `%APPDATA%\WTToolbox`, except when you
explicitly ask it to modify the game configuration or install a sound mod, in
which case it backs the original files up first.

## Vehicle index data

`src/wttoolbox/assets/vehicles.json` is generated by
`tools/build_vehicle_index.py`. It holds **3,251 factual records** - a vehicle's
code name, display name, nation, rank and class - read from the public War
Thunder Wiki:

* https://wiki.warthunder.com/sitemap-units.xml (which pages exist)
* the tech-tree routes `/ground`, `/aviation`, `/helicopters`, `/ships`, `/boats`
* individual `/unit/<code>` pages, for the vehicles the tech tree no longer lists

The file contains only these short factual identifiers. It does **not** contain
wiki article text, images, tables, descriptions or any other creative content
from the wiki, and it is not a substitute for the wiki. When you use the
vehicle comparison feature at runtime, the app fetches the actual statistics
from the wiki over the network and shows the source URL for every value.

removed, please open an issue.
